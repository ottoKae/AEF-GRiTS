# AEF 网页下载工作台

## 定位与入口

主路线为**本地运行、网页操作**：Python在用户电脑下载，浏览器是操作界面。
公开官网只负责安装介绍和传播，不保管凭据或传输影像；官网尚未部署。
原简洁GUI和网页工作台共用一个Python服务和同一套下载器。
本期仅接入AlphaEarth Foundations（AEF）年度64维、10米特征，未新增其他卫星产品。

| 入口 | 用途 |
|---|---|
| `http://127.0.0.1:5555/` | 原简洁界面：点位或格网、年份、存储位置 |
| `http://127.0.0.1:5555/portal` | 网页工作台：产品选择、规划表、地图、下载管理 |

左侧定义任务；地图显示AOI和后端解析的真实格网；下方切换规划结果与下载管理。
顶部“数据目录”采用产品勾选形式，目前只有AEF可选。Tessera产品明确禁用。
**Tessera 0.1°格网是AEF的存储单元，不表示下载Tessera特征。**

## 本地启动

从仓库或解压后的源码ZIP目录安装一次；推荐独立Python 3.11/3.12环境：

```powershell
python -m pip install ".[download,web]"
aef-grits-web
```

启动器自动打开`http://127.0.0.1:5555/portal`。若命令不在PATH，同一环境执行
`python -m webapp.launcher`。安装后无须一直在仓库目录运行。
填写**自己的**Earth Engine Project，检测/建立本机凭据后验证访问；下载过程不自动弹出登录。
认证详见[认证说明](authentication.zh-CN.md)。

可指定磁盘与端口；下面的路径需换成自己电脑上的可写目录：

```bash
aef-grits-web --output-root /your/data/aef --port 5555
# 不自动打开浏览器
python -m webapp.launcher --no-browser
```

默认数据目录为用户目录下`Downloads/AEF-GRiTS`。状态/日志分别位于Windows的
`%LOCALAPPDATA%/AEF-GRiTS`、macOS的`~/Library/Application Support/AEF-GRiTS`，
或Linux的`$XDG_STATE_HOME/aef-grits`（未设置时`~/.local/state/aef-grits`）。
本机模式支持系统文件夹选择，可选择其他磁盘；网页内目录浏览仍限制在已配置输出根目录内。

复用旧任务时先停止旧实例，再通过`--state-dir`和`--output-root`指定旧`webapp/runs`
与`webapp/output`的绝对路径。不会自动搬迁、删除数据，也不会自动重启当前5555服务。
关闭浏览器不停止Python；退出Python、休眠或断网可能中断任务，重启后主动续传。
Linux持续下载建议使用ext4/XFS，并遵守现有存储预检，不使用已发生阻塞的NTFS盘。

## 一次任务的操作

界面采用P0—P3四步，下载主路线是GEE：

1. **P0 数据源与连接**：填写Project ID（例如`my-earthengine-project`，不是名称、邮箱或密码）。
   按当前主按钮操作：检查凭据，没有凭据时主动前往Google授权，再验证连接。
   验证通过后自动收起设置；要更换Project时展开“连接设置”。
   找到凭据或完成Google登录不等于Project验证通过。认证等待可取消；已有ADC也可验证。
   共享OAuth模式继续使用“前往Google登录授权”。项目需注册Earth Engine、启用API并允许当前账号使用。
2. **P1 选择位置与提取方式**：保持AEF勾选，选择点位或格网。

   - 点位：CSV使用`sample_id,lon,lat`，经纬度为WGS84；或上传含完整配套文件和`.prj`的点Shapefile。
     首次试用可下载P1中的四点CSV示例，上传并选择2025年；这是小样本，不代表全球覆盖验收。
   - 格网：选MGRS或Tessera 0.1°，上传面Shapefile/ZIP，或在地图上矢量绘制。
   - 地图选点：切换“地图选点”，在底图单击添加；单击点标记删除。浏览器生成WGS84点表，沿用CSV预检和Parquet下载。
   - 地图选格网：范围上传/绘制后，点击“显示相交格网 / 重置选择”，单击黄色格网取消或灰色格网选中。
     选中的子集会在后端重新验证、计算数据量并签发新计划。不能全不选；不支持选择当前AOI之外的格网。
     这是下载完整选中格网，不是仅裁剪矢量内部像元。

3. **P2 年份与查询**：年份可多选；预览格网使用当前Project/年份，调整后重新预检。
4. **P3 本机存储与下载**：点击文件夹框打开系统目录选择，可选择其他磁盘；任务在该目录内
   自动建立独立子目录。格网可选Zarr、Zarr + GeoTIFF或仅GeoTIFF；点位保持Parquet。

系统选择取消时保留原设置；改目录后必须重新预检，检查的是新目录所在磁盘。无法打开系统
窗口时，使用旁边的网页目录浏览入口。系统窗口由本机Python的独立子进程调用Tk，不是浏览器
上传整个文件夹；不需要把文件传到官网。无桌面会话、远程共享模式或缺少Tk时使用网页浏览。
若要为Debian/Ubuntu系统Python补齐Tk，安装发行版`python3-tk`系统包，而不是pip包。

公开COG源选项目前仅提供实验连通检查/读取库，全球索引与GUI下载尚未贯通。
它不需要GEE登录，但连通成功不代表可以从该入口发起下载。

随后执行：

1. **检索 / 预检**：检查输入、CRS、格网ID、容量和可用磁盘；查看下方规划表。
   点击格网ID可定位地图。预检本身**不会发起AEF下载**。
2. **确认下载**：再次确认后进入已有任务队列。修改产品、范围、格网选择、年份或目录后，需要重新预检。
3. **下载管理**：查看状态、进度、当前格网块处理速率/ETA、日志、输出路径与完成验证。
   可取消排队/运行任务；认证失效时重新登录，再选择认证后续传。

“检索”是本地任务规划，不是逐景影像目录查询。AEF是年度特征产品，没有照搬参考截图
中的单景日期、单景云量或缩略图检索；实际覆盖和空值以下载后的验证结果为准。
“导出计划”保存JSON摘要，不包含认证令牌、签名`plan_id`或Project ID，也不能直接重放提交。

账号授权用于确认数据访问身份，Project用于指定执行Earth Engine操作的云项目；两者不是同一个概念。
本机模式的凭据保存在用户电脑，不上传公开官网，也不收集Google密码。
官方说明：[Authentication and Initialization](https://developers.google.com/earth-engine/guides/auth)。

### 按钮灰色与准备进度

按钮上方显示四项准备检查，每项25%：连接、文件/范围、年份、已配置存储。
缺失项会直接列出；绘制范围需双击结束，GEE连接需通过Project与AEF验证。
目录可以留空，由任务自动命名。100%只表示表单就绪，不代表数据下载或磁盘预检已完成。
点击预检/下载后显示不定进度条及阶段文字；服务器预检未提供细分进度，不显示虚构百分比。
任务提交成功后，到下方任务记录查看实际数据下载进度。

## 坐标与产物

- 地图显示使用Web Mercator（EPSG:3857），交换AOI使用WGS84（EPSG:4326）。
- 点位规范化为WGS84后，按 `native-utm-v1` 读取所在的原生UTM 10米像元，输出
  分片Parquet、逐年源资产／像元坐标、`.native.json` 与catalog；WGS84是点坐标，
  不是把AEF重投影为经纬度栅格。离线预检不代表已核验远端源网格。
- 格网下载核验完整64维的源CRS、像元边界及资产版本，拒绝跨UTM填补和错位参考格网；
  旧协议成果保持原样，不能作为新协议断点续传。正式下载使用新的输出目录。
- MGRS与0.1°格网的AEF数据以规划中报告的UTM CRS、10米像元写入所选栅格格式。
  0.1°只是地理索引单元，不是0.1°像元分辨率。
- 选择Zarr + GeoTIFF后，每个Zarr旁的`.geotiff`目录保存每年一个64波段float32 TIFF，
  采用无损DEFLATE压缩，保留CRS、transform、A00–A63和NaN NoData。
  大影像使用BigTIFF（未压缩量达到4 GiB时明确启用）。也可用格网CLI的`--export-geotiff`。
- 选择仅GeoTIFF（CLI为`--geotiff-only`）时，先用本任务临时Zarr缓存下载，TIFF校验成功
  后只清理该缓存；最终是TIFF及catalog/manifest/报告。失败时保留缓存供续传，不删除已有Zarr。
  两种TIFF模式均按窗口导出，峰值磁盘都需容纳Zarr缓存和TIFF；仅GeoTIFF不是免缓存直写模式。
  当前Linux NTFS/NTFS3输出不允许TIFF导出，需使用原生文件系统。点位仍是Parquet。
- 下载管理中的“块/s”来自下载器的进度事件，不代表网络MB/s；没有该字段时显示“—”。
- 未压缩容量是估计，不是已传输字节数或最终压缩磁盘占用。

**产物写在运行Python服务的机器上。** 本机运行时即本机路径；部署到服务器后即服务器路径。
本机文件夹窗口选择的是Python可写路径，不使用浏览器文件保存接口，也不打包ZIP传回。
远程部署只提供受限网页目录浏览，数据仍写到服务器；转到访问者电脑需另行文件传输。
TIFF运行验证检查结构、来源元数据和记录大小，不是全像元扫描。仅GeoTIFF产物不依赖临时缓存。
请用QGIS或Rasterio读取TIFF；其catalog不能作为`AEFZarr`或`AEFResolver`的Zarr索引。
读取方法见
[主README](../README.zh-CN.md#读取结果)。

## 多用户网页部署的边界

本次完成网页入口和交互，不自动发布公网网站，也未修改既有监听地址。
`local`模式只适合可信本地用户，**不能直接作为公开网站**。
校园共享使用必须配置既有的每用户OAuth、HTTPS反向代理、允许的域名和数据存储位置，
每位用户使用自己的Google身份与Project。参见[Web部署说明](../webapp/README.md#authentication-modes)。
任务与输出沿用现有用户隔离，计划沿用一次性签名和过期校验。
