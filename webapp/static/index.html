Project ID 与授权说明

填写 Cloud Project ID，不是项目名称、邮箱或密码。该项目需注册 Earth Engine 并启用 API，您的 Google 账号需有访问权限。

还没有项目？先按 Google 官方指引创建或注册项目，再把 Project ID 填到这里。

本机模式使用您的 EE/ADC 凭据。已有凭据可直接验证；需要登录时，点击 Google 授权，在 Google 官方页面完成操作。找到凭据不等于能访问数据，下载前仍需验证连接。

授权凭据由 Earth Engine 保存在当前用户的 .config/earthengine/credentials，不是 netrc，也不保存您的 Google 密码。授权后点击“验证连接”。
