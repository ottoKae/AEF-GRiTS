安装并打开工具

首次安装需要 Python，之后从浏览器操作。

新版工作台正在验收，安装包尚未发布。以下说明用于配套预览源码；请勿下载 main 代替。通过验收后，这里会提供固定版本的下载链接。
1

准备 Python 和源码

推荐 Python 3.12，也支持 3.11。

拿到配套预览源码后，解压并在含 pyproject.toml 的文件夹打开终端。不要在 ZIP 内运行。

2

首次安装，再启动

安装只做一次。下次使用时，直接运行启动命令。

Windows / PowerShell
首次安装
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install ".[download,web]"
启动工具
.\.venv\Scripts\python.exe -m webapp.launcher

使用 Python 3.11 时，将 -3.12 换成 -3.11。

macOS / Linux / Terminal
首次安装
python3 -m venv .venv
.venv/bin/python -m pip install ".[download,web]"
启动工具
.venv/bin/python -m webapp.launcher

先用 python3 --version 确认版本。Linux 缺少 venv 时按发行版说明安装；不要使用 sudo pip。

已有 conda 环境？

在自己的环境中安装，不必再创建 venv：

python -m pip install ".[download,web]"
python -m webapp.launcher

3. 打开下载页面

运行启动命令后，浏览器会自动打开。没有打开时，点击下方按钮。

打开下载页面

下载时请保持启动工具的终端运行。

页面打不开？

确认启动命令仍在运行，再打开 http://127.0.0.1:5555/portal。只点击网页按钮不会启动 Python。

若提示端口被占用，在启动命令后加 --port 5556，再打开终端显示的新地址。

以后怎么启动或更新？

再次使用时，在同一文件夹运行启动命令。

更新前先完成或取消下载并关闭旧服务。解压新版源码后，在新版目录按上方步骤安装，再启动。只替换文件或刷新网页不会更新已安装的 Python 包。

开始下载

在刚打开的下载页面中，完成以下设置。

连接 Google

检查本机凭据，按提示授权或验证。填写自己的 Earth Engine Project；这里不需要 Google 密码。

选择位置

上传点位或边界文件，也可以直接在地图上选点、圈选区域。

选择年份和文件夹

勾选需要的年份，选好文件格式和保存位置。

确认下载

检查范围和磁盘空间，确认后开始下载。进度在下载管理中查看。

目前通过 Google Earth Engine（GEE）下载，需要授权。免登录下载仍在测试中。

第一次可用工作台提供的四点 CSV 示例，选择 2025 年。完成后在下载管理中查看“结果”或复制保存路径。

第一次使用 GEE，怎么登录？

还没有 Project？先按 Google 的项目开通指南创建或选用一个 Cloud 项目，完成 Earth Engine 注册并确认账号权限。把项目 ID 填到工作台，不是项目名称或邮箱。

点击工作台中的 Google 授权，在 Google 页面登录。浏览器没有自动打开时，使用工作台显示的授权链接，并保持工具运行。登录后还要验证 Project 和 AEF 访问；登录成功不代表项目已开通。

需要更换授权时，在连接设置中主动重新授权，再验证连接。请先完成或取消正在下载的任务；不要把授权链接或凭据文件发给他人。

通常在页面中操作即可。也可以在安装目录运行以下命令：

Windows 认证命令
.\.venv\Scripts\python.exe -m aef_grits.auth_cli login --source earthengine --auth-mode localhost --project YOUR_GEE_PROJECT
.\.venv\Scripts\python.exe -m aef_grits.auth_cli verify --source auto --project YOUR_GEE_PROJECT --check-aef
macOS / Linux 认证命令
.venv/bin/python -m aef_grits.auth_cli login --source earthengine --auth-mode localhost --project YOUR_GEE_PROJECT
.venv/bin/python -m aef_grits.auth_cli verify --source auto --project YOUR_GEE_PROJECT --check-aef

把 YOUR_GEE_PROJECT 换成自己的项目 ID。不要分享密码或凭据文件；下载过程中不会自动弹出登录。

Google 官方认证说明

下载后得到什么？

点位保存为表格，区域保存为栅格。文件都在您选择的文件夹中。

下载内容文件格式用途
点位Parquet按点位和年份读取特征，用于统计或模型训练。
区域Zarr按年份或位置读取，适合多年度分析。
区域GeoTIFF每个格网每年一个 64 波段栅格，可用 QGIS 等软件打开。
格式和存储说明

区域下载可以只保留 TIFF，也可以同时保留 Zarr。生成 TIFF 需要临时 Zarr 空间；验证成功后才清理本任务的缓存，失败时保留以便续传。

AEF 是特征数据，不是普通卫星照片。MGRS 和 0.1°只是存储格网的选择，下载的仍是 AEF。

默认保存到下载文件夹中的 AEF-GRiTS，也可以选择其他磁盘。若在远程服务器运行，文件保存在服务器，不会自动传回电脑。

常见问题

关掉网页，下载会停止吗？

只要启动工具的终端还在运行，关闭网页不会停止下载。请避免关闭终端或让电脑休眠。需要停止时，在下载管理中取消任务。

下载失败了怎么办？

先看任务中的报错，检查网络、账号权限或磁盘空间。保留已下载的文件和任务记录，便于解决问题后续传。

下载按钮为什么是灰色的？

查看页面提示，补齐尚未完成的设置。修改范围、年份或 Project 后，需要重新检查。

需要什么网络条件？

运行工具的电脑需要能够访问 Google。官网不提供网络代理，也不提供他人账号的下载额度。

隐私与数据许可

官网不收集账号、样本或凭据，也不使用第三方统计脚本。工具在您的电脑上运行；查询时，必要的坐标和请求会发送给 Google。地图底图遵守其提供方的使用规则。

AEF-GRiTS 不是 Google 官方服务。研究中请分别引用本工具与原始数据，并遵守数据许可。
